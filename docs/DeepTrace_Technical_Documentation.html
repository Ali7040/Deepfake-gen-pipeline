1. Executive Summary

DeepTrace is a production-grade face manipulation framework that leverages state-of-the-art deep learning models for real-time face swapping. The system uses a multi-stage pipeline comprising:

  • Face Detection: YOLO-Face, RetinaFace, SCRFD
  • Face Recognition: ArcFace with ResNet-50 backbone
  • Landmark Detection: 2DFAN-4 Hourglass Network
  • Face Swapping: InsWapper, GhostFace, HyperSwap
  • Enhancement: GFPGAN, Real-ESRGAN

Key Innovation: All models use Convolutional Neural Networks (CNNs), optimized for spatial feature extraction in images, rather than LSTMs (sequential data) or Transformers (computationally expensive).

3. Deep Learning Models

3.1 Why CNNs, Not LSTMs or Transformers?

Architecture Best For Why Not Used
CNNs Spatial data (images) ✅ USED - Perfect for face processing
LSTMs Sequential data (speech, time series) ❌ Faces are spatial, not temporal
Transformers Long-range dependencies ❌ Too slow for real-time, high memory

Key Insight: Face images require local feature extraction (edges, textures, facial features). CNNs excel at this through convolutional filters that are:
- Translation invariant: Detect features regardless of position
- Hierarchical: Build complex features from simple ones
- Efficient: Fewer parameters than fully connected layers

def detect_faces(vision_frame: VisionFrame) -> Tuple[List[BoundingBox], List[Score], List[FaceLandmark5]]:
    """
    Detect faces in the input frame using the selected detector model.

    Args:
        vision_frame: Input image as numpy array (H, W, 3)

    Returns:
        Tuple of (bounding_boxes, face_scores, face_landmarks_5)
    """
    # Add margin padding for faces near edges
    margin_top, margin_right, margin_bottom, margin_left = prepare_margin(vision_frame)
    margin_vision_frame = numpy.pad(
        vision_frame, 
        ((margin_top, margin_bottom), (margin_left, margin_right), (0, 0))
    )

    all_bounding_boxes: List[BoundingBox] = []
    all_face_scores: List[Score] = []
    all_face_landmarks_5: List[FaceLandmark5] = []

    # Use YOLO-Face for fast detection
    if state_manager.get_item('face_detector_model') == 'yolo_face':
        bounding_boxes, face_scores, face_landmarks_5 = detect_with_yolo_face(
            margin_vision_frame, 
            state_manager.get_item('face_detector_size')
        )
        all_bounding_boxes.extend(bounding_boxes)
        all_face_scores.extend(face_scores)
        all_face_landmarks_5.extend(face_landmarks_5)

    # Adjust for margin offset
    all_bounding_boxes = [
        normalize_bounding_box(bbox) - numpy.array([margin_left, margin_top, margin_left, margin_top]) 
        for bbox in all_bounding_boxes
    ]

    return all_bounding_boxes, all_face_scores, all_face_landmarks_5

4.3 YOLO-Face Detection Process

def detect_with_yolo_face(vision_frame: VisionFrame, face_detector_size: str):
    """
    YOLO-Face detection implementation.

    YOLO (You Only Look Once) processes the entire image in a single forward pass,
    making it extremely fast for real-time applications.
    """
    bounding_boxes = []
    face_scores = []
    face_landmarks_5 = []

    # Get detector settings
    face_detector_score = state_manager.get_item('face_detector_score')
    face_detector_width, face_detector_height = unpack_resolution(face_detector_size)

    # Resize frame to detector input size
    temp_vision_frame = restrict_frame(vision_frame, (face_detector_width, face_detector_height))
    ratio_height = vision_frame.shape[0] / temp_vision_frame.shape[0]
    ratio_width = vision_frame.shape[1] / temp_vision_frame.shape[1]

    # Prepare input tensor
    detect_vision_frame = prepare_detect_frame(temp_vision_frame, face_detector_size)
    detect_vision_frame = normalize_detect_frame(detect_vision_frame, [0, 1])  # Normalize to [0,1]

    # Run ONNX inference
    detection = forward_with_yolo_face(detect_vision_frame)
    detection = numpy.squeeze(detection).T  # Shape: (num_detections, 15)

    # Split detection outputs
    bounding_boxes_raw, face_scores_raw, face_landmarks_5_raw = numpy.split(
        detection, [4, 5], axis=1
    )

    # Filter by confidence score
    keep_indices = numpy.where(face_scores_raw > face_detector_score)[0]

    if numpy.any(keep_indices):
        # Scale bounding boxes back to original image size
        for bounding_box_raw in bounding_boxes_raw[keep_indices]:
            bounding_boxes.append(numpy.array([
                (bounding_box_raw[0] - bounding_box_raw[2] / 2) * ratio_width,
                (bounding_box_raw[1] - bounding_box_raw[3] / 2) * ratio_height,
                (bounding_box_raw[0] + bounding_box_raw[2] / 2) * ratio_width,
                (bounding_box_raw[1] + bounding_box_raw[3] / 2) * ratio_height
            ]))

        # Extract landmarks
        face_scores = face_scores_raw[keep_indices].ravel().tolist()
        face_landmarks_5_raw[:, 0::3] *= ratio_width
        face_landmarks_5_raw[:, 1::3] *= ratio_height

        for face_landmark_raw_5 in face_landmarks_5_raw[keep_indices]:
            face_landmarks_5.append(numpy.array(face_landmark_raw_5.reshape(-1, 3)[:, :2]))

    return bounding_boxes, face_scores, face_landmarks_5

5.2 ArcFace Loss Function

The key innovation of ArcFace is the Additive Angular Margin Loss:

L_ArcFace = -log( exp(s·cos(θ_y + m)) / (exp(s·cos(θ_y + m)) + Σ exp(s·cos(θ_j))) )

Where:
- θ: Angle between feature vector and class center
- m: Angular margin (typically 0.5) - makes classification harder
- s: Feature scale (typically 64) - for numerical stability

Why Angular Margin?
- Creates tighter intra-class clusters (same person → similar embeddings)
- Creates larger inter-class gaps (different people → distant embeddings)
- Results in 99%+ accuracy on LFW benchmark

5.3 Code Implementation: Face Recognition

def calculate_face_embedding(temp_vision_frame: VisionFrame, 
                             face_landmark_5: FaceLandmark5) -> Tuple[Embedding, Embedding]:
    """
    Extract 512-dimensional face embedding using ArcFace.

    Args:
        temp_vision_frame: Input image containing the face
        face_landmark_5: 5-point facial landmarks for alignment

    Returns:
        Tuple of (raw_embedding, normalized_embedding)
    """
    # Get model configuration
    model_template = get_model_options().get('template')  # 'arcface_112_v2'
    model_size = get_model_options().get('size')  # (112, 112)

    # Step 1: Warp face to canonical template using landmarks
    crop_vision_frame, matrix = warp_face_by_face_landmark_5(
        temp_vision_frame, 
        face_landmark_5, 
        model_template, 
        model_size
    )

    # Step 2: Normalize pixel values to [-1, 1]
    crop_vision_frame = crop_vision_frame / 127.5 - 1

    # Step 3: Convert BGR to RGB and transpose to CHW format
    crop_vision_frame = crop_vision_frame[:, :, ::-1].transpose(2, 0, 1).astype(numpy.float32)

    # Step 4: Add batch dimension
    crop_vision_frame = numpy.expand_dims(crop_vision_frame, axis=0)

    # Step 5: Run inference through ArcFace network
    face_embedding = forward(crop_vision_frame)
    face_embedding = face_embedding.ravel()  # Flatten to 1D (512,)

    # Step 6: L2 Normalize the embedding
    face_embedding_norm = face_embedding / numpy.linalg.norm(face_embedding)

    return face_embedding, face_embedding_norm


def forward(crop_vision_frame: VisionFrame) -> Embedding:
    """
    Run ArcFace ONNX inference.
    """
    face_recognizer = get_inference_pool().get('face_recognizer')

    with conditional_thread_semaphore():
        face_embedding = face_recognizer.run(None, {
            'input': crop_vision_frame
        })[0]

    return face_embedding

def detect_with_2dfan4(temp_vision_frame: VisionFrame, 
                       bounding_box: BoundingBox, 
                       face_angle: Angle) -> Tuple[FaceLandmark68, Score]:
    """
    Detect 68 facial landmarks using 2DFAN-4 model.

    The model processes a cropped face region and outputs
    heatmaps for each landmark, which are then converted to coordinates.
    """
    model_size = create_static_model_set('full').get('2dfan4').get('size')  # (256, 256)

    # Calculate scale and translation for face cropping
    scale = 195 / numpy.subtract(bounding_box[2:], bounding_box[:2]).max().clip(1, None)
    translation = (model_size[0] - numpy.add(bounding_box[2:], bounding_box[:2]) * scale) * 0.5

    # Apply rotation for tilted faces
    rotation_matrix, rotation_size = create_rotation_matrix_and_size(face_angle, model_size)

    # Warp face to canonical position
    crop_vision_frame, affine_matrix = warp_face_by_translation(
        temp_vision_frame, translation, scale, model_size
    )
    crop_vision_frame = cv2.warpAffine(crop_vision_frame, rotation_matrix, rotation_size)

    # Optimize contrast for dark images
    crop_vision_frame = conditional_optimize_contrast(crop_vision_frame)

    # Prepare input tensor: HWC → CHW, normalize to [0, 1]
    crop_vision_frame = crop_vision_frame.transpose(2, 0, 1).astype(numpy.float32) / 255.0

    # Run inference
    face_landmark_68, face_heatmap = forward_with_2dfan4(crop_vision_frame)

    # Convert heatmap coordinates back to image space
    face_landmark_68 = face_landmark_68[:, :, :2][0] / 64 * 256
    face_landmark_68 = transform_points(face_landmark_68, cv2.invertAffineTransform(rotation_matrix))
    face_landmark_68 = transform_points(face_landmark_68, cv2.invertAffineTransform(affine_matrix))

    # Calculate confidence score
    face_landmark_score_68 = numpy.amax(face_heatmap, axis=(2, 3))
    face_landmark_score_68 = numpy.mean(face_landmark_score_68)
    face_landmark_score_68 = numpy.interp(face_landmark_score_68, [0, 0.9], [0, 1])

    return face_landmark_68, face_landmark_score_68

7.2 AdaIN (Adaptive Instance Normalization)

The key mechanism for transferring identity:

def AdaIN(content, style):
    """
    Adaptive Instance Normalization

    Transfers the 'style' (identity) from source to 'content' (target pose/expression)

    Args:
        content: Target face latent features (z_target)
        style: Source identity embedding (e_source)

    Returns:
        Modified latent features with source identity
    """
    # Normalize content features
    content_mean = numpy.mean(content, axis=(2, 3), keepdims=True)
    content_std = numpy.std(content, axis=(2, 3), keepdims=True)
    normalized = (content - content_mean) / (content_std + 1e-5)

    # Apply style statistics
    style_mean = style[:, :256]  # First half of embedding
    style_std = style[:, 256:]   # Second half of embedding

    return normalized * style_std + style_mean

7.3 Code Implementation: Face Swapping

def swap_face(source_face: Face, target_face: Face, temp_vision_frame: VisionFrame) -> VisionFrame:
    """
    Perform face swap between source and target.

    Pipeline:
    1. Warp target face to template
    2. Extract source identity embedding
    3. Run swapper model
    4. Create masks for blending
    5. Paste result back to original frame
    """
    model_template = get_model_options().get('template')  # 'arcface_128'
    model_size = get_model_options().get('size')  # (128, 128)
    pixel_boost_size = unpack_resolution(state_manager.get_item('face_swapper_pixel_boost'))

    # Step 1: Warp target face using 68 landmarks
    crop_vision_frame, affine_matrix = warp_face_by_face_landmark_5(
        temp_vision_frame, 
        target_face.landmark_set.get('5/68'), 
        model_template, 
        pixel_boost_size
    )

    crop_masks = []

    # Step 2: Create masks for blending
    if 'box' in state_manager.get_item('face_mask_types'):
        box_mask = create_box_mask(
            crop_vision_frame, 
            state_manager.get_item('face_mask_blur'),
            state_manager.get_item('face_mask_padding')
        )
        crop_masks.append(box_mask)

    if 'occlusion' in state_manager.get_item('face_mask_types'):
        occlusion_mask = create_occlusion_mask(crop_vision_frame)
        crop_masks.append(occlusion_mask)

    # Step 3: Process through swapper model
    pixel_boost_vision_frames = implode_pixel_boost(crop_vision_frame, pixel_boost_total, model_size)
    temp_vision_frames = []

    for pixel_boost_vision_frame in pixel_boost_vision_frames:
        # Prepare input
        pixel_boost_vision_frame = prepare_crop_frame(pixel_boost_vision_frame)

        # Forward pass through swapper
        pixel_boost_vision_frame = forward_swap_face(source_face, target_face, pixel_boost_vision_frame)

        # Normalize output
        pixel_boost_vision_frame = normalize_crop_frame(pixel_boost_vision_frame)
        temp_vision_frames.append(pixel_boost_vision_frame)

    # Step 4: Reconstruct high-res result
    crop_vision_frame = explode_pixel_boost(temp_vision_frames, pixel_boost_total, model_size, pixel_boost_size)

    # Step 5: Combine masks
    crop_mask = numpy.minimum.reduce(crop_masks).clip(0, 1)

    # Step 6: Paste back to original frame
    paste_vision_frame = paste_back(temp_vision_frame, crop_vision_frame, crop_mask, affine_matrix)

    return paste_vision_frame


def forward_swap_face(source_face: Face, target_face: Face, crop_vision_frame: VisionFrame) -> VisionFrame:
    """
    Run the face swapper ONNX model.
    """
    face_swapper = get_inference_pool().get('face_swapper')
    model_type = get_model_options().get('type')
    face_swapper_inputs = {}

    # Prepare source embedding
    source_embedding = prepare_source_embedding(source_face)
    source_embedding = balance_source_embedding(source_embedding, target_face.embedding)

    face_swapper_inputs['source'] = source_embedding
    face_swapper_inputs['target'] = crop_vision_frame

    # Run inference
    with conditional_thread_semaphore():
        crop_vision_frame = face_swapper.run(None, face_swapper_inputs)[0][0]

    return crop_vision_frame

8.2 Poisson Blending

Poisson blending solves a partial differential equation to seamlessly merge the swapped face:

Mathematical Formulation:

∇²f = ∇²g   (inside face region Ω)
f = f*      (on boundary ∂Ω)

Where:
- f: Blended result
- g: Swapped face (guidance)
- f*: Original background
- ∇²: Laplacian operator

This ensures:
- Gradient preservation: Textures from swapped face are maintained
- Boundary continuity: Seamless transition at edges
- Color matching: Automatically adjusts to target lighting

10.1 Complete Face Swap Pipeline

#!/usr/bin/env python3
"""
DeepTrace Face Swap Pipeline
Complete implementation showing the full workflow
"""

import cv2
import numpy as np
from deeptrace import state_manager, face_analyser
from deeptrace.processors.modules.face_swapper import core as face_swapper
from deeptrace.vision import read_static_image, write_image


def initialize_deeptrace():
    """Initialize DeepTrace with optimized settings"""
    # Execution providers
    state_manager.init_item('execution_providers', ['CUDAExecutionProvider', 'CPUExecutionProvider'])

    # Face detection settings
    state_manager.init_item('face_detector_model', 'yolo_face')  # Fast detector
    state_manager.init_item('face_detector_size', '640x640')
    state_manager.init_item('face_detector_score', 0.5)

    # Face swapper settings
    state_manager.init_item('face_swapper_model', 'inswapper_128_fp16')  # FP16 for speed
    state_manager.init_item('face_recognizer_model', 'arcface_inswapper')
    state_manager.init_item('face_landmarker_model', '2dfan4')


def process_face_swap(source_path: str, target_path: str, output_path: str) -> bool:
    """
    Perform face swap between source and target images.

    Args:
        source_path: Path to source image (face to copy)
        target_path: Path to target image (where to apply)
        output_path: Path to save result

    Returns:
        True if successful, False otherwise
    """
    # Step 1: Read images
    source_frame = read_static_image(source_path)
    target_frame = read_static_image(target_path)

    if source_frame is None or target_frame is None:
        print("Error: Failed to read images")
        return False

    # Step 2: Detect and analyze faces in source image
    # This extracts: bounding box, 68 landmarks, 512-D embedding
    source_faces = face_analyser.get_many_faces([source_frame])
    if not source_faces:
        print("Error: No face found in source image")
        return False

    source_face = source_faces[0]  # Use first detected face

    # Step 3: Detect faces in target image
    target_faces = face_analyser.get_many_faces([target_frame])
    if not target_faces:
        print("Error: No face found in target image")
        return False

    # Step 4: Perform face swap
    # This runs through: detection → landmarks → swap → blend
    result_frame = face_swapper.process_frame(
        source_face=source_face,
        temp_vision_frame=target_frame
    )

    # Step 5: Save result
    success = write_image(output_path, result_frame)

    return success


if __name__ == '__main__':
    initialize_deeptrace()

    success = process_face_swap(
        source_path='source.jpg',
        target_path='target.jpg',
        output_path='result.jpg'
    )

    if success:
        print("Face swap completed successfully!")
    else:
        print("Face swap failed!")
