1. Introduction

1.1 Why Deep Learning for Face Swapping?

Face swapping is a complex computer vision task that requires understanding facial geometry, identity features, expressions, and seamless blending. Traditional approaches using geometric transformations failed to produce realistic results because:

  • Facial identity is abstract: A face's identity isn't defined by pixel positions but by complex feature relationships
  • Expressions and poses vary infinitely: Hard-coding transformations can't handle all variations
  • Blending artifacts are difficult to remove: Simple copy-paste creates visible boundaries

Deep Learning Solution: Neural networks learn these complex relationships from millions of face images, enabling: - Automatic feature extraction - Identity-preserving transformations - Photorealistic generation - Real-time processing

1.2 The Multi-Model Pipeline Approach

Rather than using a single monolithic model, DeepTrace employs a modular pipeline where each specialized model handles one task:

┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   DETECT    │───▶│  LANDMARKS  │───▶│  RECOGNIZE  │───▶│    SWAP     │
│  (Where?)   │    │  (Shape?)   │    │  (Who?)     │    │  (Change!)  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘

Why this approach? - Specialization: Each model is optimized for its specific task - Flexibility: Components can be swapped without retraining others - Debugging: Easier to identify which stage causes issues - Efficiency: Can use lighter models where speed is critical

2. Face Detection Models

What is Face Detection?

Face detection is the task of locating human faces in an image and providing their bounding box coordinates. It answers: "Where are the faces in this image?"

Output: For each face found: - Bounding box: (x_min, y_min, x_max, y_max) - Confidence score (0-1) - Optional: 5 facial landmarks (eyes, nose, mouth corners)

2.1 YOLO-Face

What is YOLO?

YOLO (You Only Look Once) is a revolutionary object detection architecture that processes an entire image in a single forward pass, unlike older methods (R-CNN) that used multiple stages.

Why "You Only Look Once"?

Traditional detectors: 1. Generate thousands of region proposals 2. Classify each region separately 3. Very slow (seconds per image)

YOLO: 1. Divides image into grid 2. Each cell predicts objects directly 3. Single pass = real-time speed

2.2 RetinaFace

What is RetinaFace?

RetinaFace is a multi-task face detection model that simultaneously performs: 1. Face detection (bounding boxes) 2. Face alignment (5 landmarks) 3. 3D face reconstruction (optional)

The Innovation: Feature Pyramid Network (FPN)

The key innovation in RetinaFace is the Feature Pyramid Network, which handles faces of all sizes effectively.

Problem: Faces in photos vary dramatically in size - Far away person: 20×20 pixels - Close-up selfie: 500×500 pixels

Solution: Process at multiple scales

2.3 SCRFD

What is SCRFD?

SCRFD (Sample and Computation Redistribution Face Detector) is a highly efficient face detector that achieves RetinaFace-like accuracy with 3x less computation.

The Innovation: Smart Resource Allocation

Traditional detectors allocate equal resources to all parts of the image. SCRFD instead: 1. Identifies where faces are likely to be 2. Allocates more computation to those regions 3. Saves resources on background areas

3. Face Recognition Model

What is Face Recognition?

Face recognition converts a facial image into a numerical representation (embedding) that captures the person's identity. Similar faces produce similar embeddings.

Key Concept: The model learns that: - Same person → embeddings close together (small distance) - Different people → embeddings far apart (large distance)

3.1 ArcFace with ResNet-50

What is ArcFace?

ArcFace (Additive Angular Margin Loss) is a face recognition method that achieves state-of-the-art accuracy by improving how the model learns to separate different identities.

The Problem with Traditional Approaches

Softmax Loss (traditional classification): - Trains model to classify faces into known identities - Creates embeddings that work for training people only - Poor generalization to new, unseen people

Why it fails for face recognition:

Training:                    Testing (new person):
┌─────────────────┐         ┌─────────────────┐
│ Person A ●      │         │ New person ?    │
│ Person B ●      │  →      │ Where to place? │
│ Person C ●      │         │ No class exists!│
└─────────────────┘         └─────────────────┘

The ArcFace Solution

ArcFace doesn't classify faces—it creates a metric space where identity is represented by position:

EMBEDDING SPACE (512 dimensions, visualized in 2D)

Softmax (messy clusters):      ArcFace (tight, separated):

       ○○                              ○○
      ○○○○                            ○○○○
        ○     △                          ○       △△
       ○○    △△△    ←  People          ○○      △△△△
            △△       not well              △       △
      □□□□           separated       □□□□□
       □□                              □□□□

                                    Much cleaner!

ArcFace Mathematical Formulation

The key innovation is adding an angular margin to make classification harder during training:

Standard Softmax:
L = -log( exp(W_y · x) / Σ exp(W_j · x) )

ArcFace Modification:
L = -log( exp(s · cos(θ_y + m)) / (exp(s · cos(θ_y + m)) + Σ exp(s · cos(θ_j))) )

Breaking it down:

  1. θ (theta): Angle between face embedding and class center
  2. Small θ = face is similar to class

  3. Large θ = face is different from class

  4. m (margin): Added angle penalty (typically 0.5 radians)

  5. Forces the model to learn MORE discriminative features

  6. Face must be "extra close" to its class to be correct

  7. s (scale): Scaling factor (typically 64)

  8. Prevents numerical instability
  9. Controls how spread out classes are

Visual Explanation of Angular Margin

WITHOUT MARGIN:                    WITH MARGIN (ArcFace):

      W_y (class center)               W_y (class center)
       ↑                                ↑
       │                                │
       │  θ                             │  θ + m (harder!)
       │ /                              │ /
       │/                               │/
       ●───────→ x (embedding)          ●───────→ x (embedding)

Decision boundary               Decision boundary 
is perpendicular               is pushed, creating
to class center                larger margin between
                               classes

Result: During training, the model must work harder to correctly classify faces, so it learns more discriminative features.

4. Landmark Detection Model

What are Facial Landmarks?

Facial landmarks are specific points on a face that define its geometry. They answer: "What is the shape of this face?"

Common landmark counts: - 5 points: Eyes (2), nose (1), mouth corners (2) - for basic alignment - 68 points: Full face shape including jaw, eyebrows, eyes, nose, mouth - 106 points: Even more detailed for high-precision applications

4.1 2DFAN-4 Hourglass Network

What is a Hourglass Network?

The Hourglass architecture is designed for tasks that require both: - Global understanding (where is the face positioned?) - Local precision (exact pixel location of each landmark)

It's called "hourglass" because of its shape:

HOURGLASS SHAPE:

Input  ──→  ████████████  ←── Full resolution (256×256)
            ████████            ↓ Downsample
              ████              ↓
               ██    ←── Bottleneck (captures context)
              ████              ↓ Upsample
            ████████            ↓
Output ←── ████████████  ←── Full resolution restored

The network compresses then expands, like sand in an hourglass!

Why This Shape Works

DOWNSAMPLE (Encoder):              UPSAMPLE (Decoder):
See LARGE patterns                 See SMALL details

┌───────────────────┐              ┌───────────────────┐
│ "There's a face   │              │ "The left eye's   │
│  in the center    │    +         │  inner corner is  │
│  of the image"    │              │  at exactly       │
│                   │              │  (127, 89)"       │
└───────────────────┘              └───────────────────┘
      CONTEXT                          PRECISION
         ↓                                ↓
         └──────────────┬─────────────────┘
                        ↓
              COMBINED: Precise landmark
              locations with full context

5. Face Swapping Models

What is Face Swapping?

Face swapping replaces the identity of one face with another while preserving: - Pose (head angle) - Expression (smile, surprise, etc.) - Lighting (shadows, highlights) - Background integration

5.1 InsWapper

What is InsWapper?

InsWapper (Identity Swapper) is an encoder-decoder neural network that performs face swapping by injecting source identity into target facial features.

AdaIN: The Key to Identity Transfer

AdaIN (Adaptive Instance Normalization) is the mechanism that transfers identity from source to target:

ADAIN OPERATION:

Input: 
  - Content features (z): Target face latent representation
  - Style (e): Source identity embedding

Process:
  1. Normalize content: z_norm = (z - μ(z)) / σ(z)
     • Remove target's identity information

  2. Apply source style: z_new = σ(e) × z_norm + μ(e)
     • Inject source's identity information

Result:
  - Content (pose/expression) from target
  - Style (identity) from source

VISUAL:

Target Features      Source Identity       Combined
                     Statistics
   [◆◆◆]                                    [○○○]
   [◆◆◆]      +      μ=0.5, σ=0.3    →     [○○○]
   [◆◆◆]             (from e)              [○○○]

   Pose info         Identity info         Target pose +
   preserved         transferred           Source identity

5.2 GhostFace

What is GhostFace?

GhostFace uses Ghost Convolutions to achieve high-quality face swapping with 50% fewer computations than traditional approaches.

Ghost Convolution Concept

Traditional convolution generates all feature maps through expensive operations. Ghost convolution claims that many feature maps are similar ("ghosts" of each other) and can be generated cheaply:

TRADITIONAL CONVOLUTION:

Input                     Output (all expensive)
[████]                    [████] ← Full conv
[████]  ──→ Conv3×3 ──→   [████] ← Full conv
[████]                    [████] ← Full conv
                          [████] ← Full conv

Total: 4 × expensive operations

GHOST CONVOLUTION:

Input                     Output (mix of expensive + cheap)
[████]                    [████] ← Full conv (intrinsic)
[████]  ──→ Conv3×3 ──→   [████] ← Cheap linear from above
[████]                    [████] ← Full conv (intrinsic)
                          [████] ← Cheap linear from above

Total: 2 × expensive + 2 × cheap
       = ~50% less computation!

6. Enhancement Models

What is Face Enhancement?

Even after face swapping, the result may have: - Artifacts: Visible boundaries, color mismatches - Low resolution: Blurry details, especially at small face sizes - Quality issues: Noise, compression artifacts

Enhancement models fix these issues.
